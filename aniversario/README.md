# 💖 Celular Mistério — Site de aniversário

Site romântico, animado e otimizado para celular.

## Personalizar
1. Abra `script.js` e edite `CONFIG` (nome e datas).
2. Em `index.html`, edite a carta, as legendas e a mensagem da surpresa.
3. Coloque suas fotos em `assets/` como `foto1 até foto7 (.jpg, .png, .jpeg ou .webp).
4. Coloque a música em `assets/musica.mp3`.

## Publicar no GitHub Pages
Settings → Pages → Branch `main` → `/ (root)` → Save.
O link ficará: `https://SEU-USUARIO.github.io/Celular-misterio/`
